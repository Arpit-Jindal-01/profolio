# ARPiT_FREELANCE — Master Asset Library

This folder is the organized master library for all freelance work by Arpit Jindal.  
It is **independent from the website code** and is not deployed to the live portfolio.

---

## Structure

```text
ARPiT_FREELANCE/
│
├── DESIGN/
│   ├── Social Media/       — Instagram posts, stories, carousels
│   ├── Posters/            — Event posters, promotional creatives
│   ├── Presentations/      — Pitch decks, slide decks
│   └── Other/              — Flyers, banners, misc design work
│
├── EXCEL/
│   ├── Dashboards/         — Interactive Excel/Sheets dashboards
│   ├── Data Cleaning/      — Data cleaning & ETL work
│   ├── Trackers/           — CRM, inventory, sales trackers
│   └── Reports/            — Business reports & performance docs
│
├── VIDEO/                  — Video editing projects
│
├── CLIENT-SAMPLES/         — Sanitized/public-safe sample deliverables
│
└── PROPOSALS/
    └── RATE-CARD.md        — Internal rate card & pricing policy
```

---

## Project Folder Convention

Each project follows this structure where applicable:

```text
PROJECT-NAME/
├── Preview/       — Optimized image/video for website, Fiverr, Upwork, proposals
├── Source/        — Original editable files (.psd, .ai, .fig, .xlsx, etc.)
├── Final/         — Final deliverables sent to client or published
└── Description.md — Project metadata (no fabricated clients/metrics)
```

---

## Privacy Policy

> **DO NOT commit:**
> - Confidential client Excel files or personal data
> - Private business data or contracts
> - API keys, passwords, or `.env` files
> - Private client communications or proposals
> - Any file that cannot legally/publicly be shared

Real client projects: include only a sanitized/public preview, not the original confidential source.

## Asset Relationship to Website

The deployed website at [arpit-jindal-01.github.io/profolio](https://arpit-jindal-01.github.io/profolio/) references optimized assets from `/assets/`.  
This library contains the master source and organized versions.  
**Do not duplicate large files unnecessarily.** One master source → optimized preview for web.
