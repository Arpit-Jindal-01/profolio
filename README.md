## 🎯 Key Features & Highlights

- **Dark Editorial Aesthetic:** Custom design system built with vanilla CSS (`#080808` background, `#8b5cf6` vibrant accents, and typography driven by Inter & Manrope).
- **Three Core Creative Modes:**
  - 🎬 **Video:** Short-form promotional reels, pacing, motion graphics, transitions, and audio mixing.
  - 🎨 **Design:** High-impact posters, social media creatives, and menu concepts.
  - 📊 **Data:** Clean spreadsheets, inventory alert systems, financial tracking, CRM lead funnels, and interactive dashboard UI previews.
- **Working Enquiry System:** Client-side form validation with encoded `mailto:` integration triggering pre-filled project inquiries directly to `jindalarpit0228@gmail.com`.
- **Dynamic Contact Configuration:** Platform links (Email, LinkedIn, GitHub) render dynamically based on available configuration. Unset freelance profiles remain hidden gracefully.
- **Performance & Accessibility:** Zero horizontal scrolling, smooth scroll navigation, native touch support on mobile, custom desktop cursor, and full `prefers-reduced-motion` compliance.
